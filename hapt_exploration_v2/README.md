# HAPT课程探索实验 v2

本目录保存2026-10-29完成的探索实验。正式课程报告已采用target20_v2结果；formal_v1作为训练统计来源与前期实验档案保留。最终提交包根目录README提供可移植的环境建立、数据准备、试运行和完整复现命令。

## 研究问题与证据口径

目标条件固定为真实HAPT六类稳定活动窗口叠加**20 dB高斯仿真噪声**，SNR仍由21名训练受试者的记录中心化功率定义。原9名测试受试者的数据及标签参与K、λ、β选择，因此称为“调参评价集”。不能将本轮最优分数说成独立测试集泛化性能。

选参后使用5个未用于本轮选参的噪声种子，再评价相同9人及完整高斯/脉冲网格。新种子仅检查对噪声实例的敏感性，不能恢复受试者层面的独立性。bootstrap区间未校正搜索选择，不是确认性显著性证据。

可以在模拟专利书中把适用场景限定在有实测收益的条件，具体条件应由本轮真实结果决定；全网格结果与失败配置保存在实验附件，以免把局部结论推广成普遍有效。没有开展专利新颖性检索，不声称可专利性。

## 调整范围

| 项目 | 本轮设置 |
|---|---|
| 不改的计算机制 | 66维特征、20 dB训练配对扰动、MI与稳定性统计、线性SVC、按人记录划分 |
| 搜索 | K=20/30/40/50/60，λ=0.05/0.1/0.25/0.5/1，β=0.05/0.1/0.2 |
| 方法 | B0全特征；B1互信息；B2互信息加冗余；A1互信息加稳定性；P完整 |
| 目标 | 原9人调参评价集上20 dB高斯条件受试者平均六类Macro-F1 |
| 选择重复 | 3个训练种子×5个调参噪声种子 |
| 平分规则 | 目标差≤0.0001时，优先干净分数高、K小、λ小、β小 |
| 对照视角 | 各方法独立调参；另以P的K/λ/β匹配去稳定性和去冗余消融 |
| 后续检查 | 新噪声种子下的干净、高斯五档、脉冲三档；不据其再次调参 |
| 计算 | 现有Python环境、CPU、单线程；没有安装新依赖 |

对含稳定性的方法搜索λ，对含冗余的方法搜索β，其余项固定0；方法参数维数不同但所有预设候选全部保存。增加机制的结果不应只与未经调参的较弱基线比较。

## 复现

从聊天工作区根目录运行。依赖沿用`outputs/hapt_project/requirements-lock.txt`，本机现有解释器为`work/.venv/Scripts/python.exe`。原官方数据包和缓存保存在work，数据来源与许可见原项目说明。没有数据包时，原DataStore按配置从UCI官网下载。

```powershell
& work/.venv/Scripts/python.exe outputs/hapt_exploration_v2/run_exploration.py smoke
& work/.venv/Scripts/python.exe outputs/hapt_exploration_v2/run_exploration.py formal
& work/.venv/Scripts/python.exe outputs/hapt_exploration_v2/audit_results.py
```

为复用训练统计，需保留`outputs/hapt_project/results/formal_v1/fit_statistics/final_seed*`，对应统计仅由21人训练集拟合；运行时核验来源及原冻结源码哈希。若从头恢复原实验，先按原项目README重现formal_v1，再执行本轮。

已完成的run_id禁止覆盖。上述命令适用于尚无本轮结果的干净复现工作区。完全重跑时在新工作区保留相同outputs/hapt_project及work数据依赖，通过`--workspace 新工作区绝对路径`显式指定它，并复制本探索项目到该工作区；这样smoke和正式结果均使用新的目录。不要把本轮探索配置覆盖原冻结配置。
