# A题技术方案 v1.0（实现依据，非最终报告）

更新时间：2026-10-28。已由用户确定：选题A、Python、16 GB内存、时间不急、暂无补充课程要求。

题名沿用：**一种基于扰动稳定性与冗余约束特征选择的手机惯性信号活动识别方法**。

当前只定义方案和实验。拟议区别是将训练扰动下的特征变化惩罚加入判别力与冗余的联合筛选；是否优于基线尚无实测结论，亦未开展专利检索，不声称专利新颖性、创造性或可授权性。

## 1. 数据版本与任务边界

为严格执行“先划分独立采集单元、后生成窗口”，将先前候选的UCI 240预分窗数据细化为其官方连续记录扩展版 **UCI 341 HAPT，压缩包README版本2.1**。这是同一手机惯性信号活动识别课题的数据实现调整，不更换选题。仅使用RawData连续信号、标注和官方受试者分组；不使用包内已提取、已归一化的561维X_train/X_test。

识别六类基本活动：1步行、2上楼、3下楼、4坐、5站、6躺。类别7—12为姿态转换，不纳入首版任务；未标注区域及跨活动边界窗口也排除。因此实验结论仅适用于已标注稳定活动窗口，不能声称完成连续在线活动分割、转换识别或实际产品验证。

数据采集是真实公开手机实验；后续噪声由程序模拟。加噪样本必须称“真实公开记录叠加仿真噪声”，不能称“真实设备噪声工况实测”。来源、许可差异和可实现性见07文件。

## 4. 窗口与标注的精确定义

README没有明确标注端点采用0基还是1基、末端是否包含。本方案不声称恢复作者的精确端点习惯，统一取保守内部区间：

`J(r,a) = [s+10, e-10)`，这里括号是Python零基半开索引。

该区间在常见的0基/1基、闭区间/半开区间解释下均处在标注内部，主动弃去边界附近采样。任何文档或代码都不得悄悄改成另一套端点解释。

每条记录从t=0开始建立`[qH, qH+L)`，q=0,1,…且qH+L≤记录长度。若完整窗口被唯一一个类别1—6的J包含则保留；否则丢弃。不拼接两个区间，不跨记录，不用测试标签移动网格起点；推理本身不需要标签，实验标签仅用于限定本次稳定活动评价域和计算指标。短于L的内部区间不产窗，所有丢弃原因计数。

先建立受试者/记录划分，再建立每个分区的窗口清单。50%重叠窗口只能在所属分区内部出现；同一原始记录的任何切片不得跨训练/验证/测试。

## 5. 66维特征的唯一实现定义

计算使用float64，不先按单窗去除均值再计算时域特征，以保留重力方向信息；仅频谱和相关系数按下述规则中心化。L=128，n=0,…,127。

每通道10维，六通道共60维；另加acc内部三对、gyro内部三对Pearson相关，共66维。列顺序：先按六个通道顺序各排列下面10项，最后排列acc_xy、acc_xz、acc_yz、gyro_xy、gyro_xz、gyro_yz。禁止在实验间改变特征表。

| 次序 | 特征 | 精确公式/规则 |
|---|---|---|
| 1 | 均值 | μ=(1/L)Σ_n x[n] |
| 2 | 总体标准差 | s=√((1/L)Σ_n(x[n]−μ)²)，ddof=0 |
| 3 | RMS | √((1/L)Σ_n x[n]²) |
| 4 | IQR | Q_0.75−Q_0.25；NumPy quantile采用method=linear |
| 5 | 平均能量 | E=(1/L)Σ_n x[n]²；保留它与RMS的已知冗余用于检验筛选，不把平方关系当未知创新 |
| 6 | 归一化频谱熵 | −Σ_(k=1..64) p_k ln(p_k)/ln64；0ln0定义为0 |
| 7 | 主频 | k*50/128，其中k是1..64上功率最大的索引；并列取最小k |
| 8 | 低频带占比 | Σ_(0.5≤ν_k<3) p_k |
| 9 | 中频带占比 | Σ_(3≤ν_k<8) p_k |
| 10 | 高频带占比 | Σ_(8≤ν_k≤20) p_k |

频谱：`w[n]=0.5−0.5cos(2πn/127)`（对称Hann）；`Z=rfft((x−μ)·w,n=128)`；`ν_k=50k/128`。单边功率`A_k=2|Z_k|²`（1≤k≤63），`A_64=|Z_64|²`，舍弃DC索引0；`p_k=A_k/Σ_(l=1..64) A_l`。不补零、不过采样；频率分辨率0.390625 Hz。

定义单窗数值阈值`a_tol=1e−12·max(1,|μ|)`（按该物理通道的数值单位）。若s≤a_tol或ΣA≤0，频谱熵、主频及三个频带占比均置0。三个频带之和不要求为1，因为(0,0.5)及(20,25]没有纳入三个频带。均值等时域特征仍保留。

相关系数：`ρ_ab = Σ(x_a−μ_a)(x_b−μ_b) / √[Σ(x_a−μ_a)²·Σ(x_b−μ_b)²]`。任一通道s≤其a_tol时置0；否则计算后只对浮点越界截断至[−1,1]。不计算加速度—陀螺仪跨单位相关。

本版不加入带参数的滤波器，避免把滤波收益混入特征筛选收益。频带边界和66维清单在最终测试前固定，其合理性来自50 Hz采样上限与低成本运动特征设计，并非声称这些频带是已验证的最优活动生理频带。

## 6. 参考功率与训练扰动

令U_r为当前训练折记录r中所有类别1—6保守内部区间的采样索引并集，同一采样只算一次。

`μ[r,c]=(1/|U_r|)Σ_(t∈U_r)x[r,t,c]`

`P[T,c]=Σ_(r∈T)Σ_(t∈U_r)(x[r,t,c]−μ[r,c])² / Σ_(r∈T)|U_r|`

先去每记录的通道均值，再汇总功率，避免固定重力DC直接决定噪声幅度。跨姿态的低频变化仍计入，故称“训练参考交流功率”，不是每个测试窗口的瞬时信号功率。单位分别为g²与(rad/s)²。若U为空、非有限或任一P≤0，停止并检查数据，不能从验证/测试数据补估。

指定参考SNR为γ dB：`σ[c]²=P[T,c]·10^(−γ/10)`。训练稳定性使用γ=20 dB，即标准差为√P的0.1倍。这是首版预设扰动，不是设备校准噪声。

在整条连续记录每个通道添加ε，而不是为每个重叠窗口独立生成噪声。同一采样在多个重叠窗中的噪声必须相同。噪声在分窗和S106之前添加；原始x不被中心化、不删除重力，也不事后归一化单窗噪声到某个SNR。完整噪声类型、种子及评价网格见05。

## 7. 训练内筛选公式

所有量仅由当前训练折求得；每折重新fit。设干净训练特征为F_ij，三次高斯训练扰动特征为F^(b)_ij，i为窗口，j为特征，b=0,1,2。

### 7.1 数值常数筛除与尺度

令`m_j=mean_i F_ij`、`s_j=std_i F_ij(ddof=0)`、`τ_j=1e−12·max(1,|m_j|)`。s_j≤τ_j的维度剔除；掩码只由干净训练特征确定。定义`a_j=max(IQR_train,j,0.1s_j,τ_j)`；0.1s_j在IQR为0但确有变化时防止除零和无限放大，τ_j只作数值下限。验证/测试使用相同掩码，不自行删列。

### 7.2 判别力

用干净训练F在训练折内拟合均值/标准差，得到Z。调用`mutual_info_classif(Z,y,discrete_features=False,n_neighbors=3,random_state=训练种子,n_jobs=1)`，得到非负估计MI_j（自然对数尺度）。其目标量为`I(F_j;Y)=Σ_y∫p(f,y)ln[p(f,y)/(p(f)p(y))]df`，实现采用该库的近邻估计，非人工离散分箱。

`I_j=MI_j/max_l MI_l`；如最大值≤0，则所有I_j=0并记录。该情况不改用测试数据估计，筛选仍可确定执行，但结果应提示训练判别信息不足。所有方法复用同一训练折/种子的MI估计。

### 7.3 稳定性与冗余

`d_j=median_(i,b)(|F^(b)_ij−F_ij|)/a_j`，`D_j=d_j/(1+d_j)`。

这里对训练窗与3次扰动等权取中位数，属于低成本经验惩罚，不是独立样本统计检验。D_j∈[0,1)，值越大越敏感。与先前草案相比，本版固定为有界变换d/(1+d)，不再保留未指定的归一化选项。

`R(j,A)=mean_(l∈A)|corr_train(F_j,F_l)|`，A为空时R=0。相关系数仅由干净训练特征估计，数值截断至[0,1]。

### 7.4 贪心规则

`Q(j|A)=I_j−λD_j−βR(j,A)`。

从A=空集开始，每次选择未选维度中Q最大的一个，加入A，直到K_eff=min(K,d)维；即使剩余评分为负也选满相同预算。若分数差≤1e−12，按66维原始列索引更小者优先。d=0时停止运行，不生成虚假分类器。若K被截短，必须记录，且同折所有筛选方法共同使用K_eff。

联合机制的可检验假设是：在保留训练判别力、限制冗余的同时，减少对训练噪声敏感特征的依赖。稳定但无判别力的特征仍可能被过强λ偏好，因此必须用干净性能约束、消融和不同噪声条件检验。

## 8. 分类器、参数与异常边界

| 项目 | 固定值或候选 | 依据/边界 |
|---|---|---|
| 窗长/步长 | 128/64 | 保持与数据公开任务常用2.56 s、50%重叠设置接近；本次重建窗口不要求复现官方窗口数 |
| 目标维数K | 20、40、60 | 对66维提供三个压缩程度；报告同K对照，避免只比较不同预算 |
| 稳定性λ | 含该项的方法使用0.25、0.5、1 | 与[0,1]判别力同量级；仅训练内部验证选；λ=0作为去稳定性消融，不混入完整方法定义 |
| 冗余β | 有冗余项时固定0.1，无时0 | 用有限惩罚保留判别力；固定而不做大网格调参，敏感性分析如另做须在开发集内 |
| 分类标准化 | StandardScaler，with_mean=True，with_std=True | 仅fit干净训练折/最终完整开发集；加噪评价只transform |
| LinearSVC | C=1、penalty=l2、loss=squared_hinge、dual=False、tol=1e−4、max_iter=20000、class_weight=None、fit_intercept=True | 所有方法相同的线性分类器，不将额外分类器调参收益计为区别特征；固定C简化预算 |
| 收敛失败 | 同配置将max_iter提高到100000，并保留两次日志 | 此为数值求解补救，不改C、特征或噪声条件；仍失败则标记失败，不能静默丢弃 |
| 非有限/错位输入 | 停止对应记录处理并记录错误 | 无缺失值插补路线；目前审计未发现非有限值、acc/gyro样本数不一致 |
| 标签重叠/越界 | 停止，查原数据 | 不用多数投票掩盖坏标签，不跨采集记录拼接 |
| 计算精度 | 特征计算float64；连续记录可读为float64并逐条处理 | 重复运行不承诺跨BLAS版本逐位相同；版本、种子、线程数均归档 |

分类形式为每类k的一对其余线性判别`h_k(z)=w_k^Tz+b_k`，输出argmax_k h_k。优化为L2正则加平方hinge损失；具体截距正则与多分类实现以锁定版本LinearSVC为准，调用参数必须完整保存。不输出未经校准的“概率”，本任务不把AUROC作为核心指标。

## 9. 实际困难与验证映射
