## 3. 数据局限与能支持的结论

| 局限 | 对实验与表述的约束 |
|---|---|
| 单类设备、腰部佩戴、受控活动 | 不能声称验证了跨设备、任意佩戴位置、日常自然场景部署 |
| 总共30人，最终测试只有9人 | 按受试者报告与重采样，不能用大量重叠窗口冒充大量独立受试者 |
| 原文件没有明确端点基准 | 采用04固定的保守内部区间；留存规则与弃窗计数，不能说精确复现官方端点解释 |
| 六类稳定活动过滤 | 测试标签用于定义稳定活动评价域，不能把其结果当成未分段连续流的完整识别效果 |
| 仿真噪声 | 高斯和脉冲仅是预设压力测试，不等同真实手机噪声、丢包、漂移、冲击或机械故障采集 |
| 本版未滤波、未研究硬件饱和 | 结论限定到本版数据处理链；没有传感器饱和、量化或佩戴位移模型 |
| 数据许可文字有版本差异 | 如将来扩展商业用途或公开再分发，需另核对权利与许可，本阶段不作该扩展 |

## 4. 当前环境已经核验的可实现性

| 项目 | 实际核验结果 | 结论 |
|---|---|---|
| 系统与内存 | Windows 11；检测物理内存16,573,128,704字节（约15.44 GiB），24逻辑CPU | 与用户16 GB描述一致；采用CPU单线程，避免内存并发 |
| 可用内存 | 检查时2,669,768,704字节（约2.49 GiB），会随其他程序变化 | 运行前再次检查，峰值RSS目标<1.5 GiB；不按总内存假定可用16 GB |
| Python | 当前工作目录独立环境`work/.venv`，Python 3.12.14 | 未改系统Python；后续以该环境明确调用 |
| 核心依赖 | NumPy 2.3.5、SciPy 1.17.1、scikit-learn 1.9.1、Matplotlib 3.11.2、PyYAML 6.0.3、psutil 7.2.2 | 已安装并成功导入；完整版本清单见08 |
| API冒烟 | rfft、mutual_info_classif、StandardScaler→LinearSVC Pipeline、PNG保存、YAML解析均通过 | 仅对明确合成的120×66小数组测试接口，无真实活动数据训练或性能计算 |
| 依赖一致性 | pip check结果为No broken requirements found | 当前独立环境依赖无已报告冲突 |
| 沙箱差异 | 科学计算动态库首次在受限沙箱下加载被系统应用控制阻止；同一环境在获准的普通桌面权限下通过 | 正式运行须使用已验证的桌面权限执行方式；不能把受限沙箱导入失败说成算法无法实现 |
| 绘图缓存 | 将MPLCONFIGDIR固定到`work/matplotlib-cache` | 避免默认用户配置目录的写入限制 |
| 数据实际体量 | 原始采样约51.4 MiB的六通道float64数值；自建全部窗口理论56.94 MiB；66维特征约4.89 MiB | 按记录、按条件顺序计算可控；文本、对象和库开销另外计入RSS |
| 性能证据边界 | 本阶段没有实现特征筛选主流程、没有训练真实数据分类器、没有打开最终性能结果 | 已确认数据与接口层面可进入编码；端到端时间、实际峰值内存和识别效果须编码后测量 |

结论：**在当前机器与已建立的独立Python环境中，按04—06的顺序处理和内存预算可实现本方案；需要使用已验证的桌面权限执行科学计算。** 尚未证明技术改进有效，也未完成全部算法实现的集成验证。
