## 2. 数据和协议落实

真实记录来自腰部手机的六通道公开采集；添加的高斯/脉冲噪声均为**仿真噪声**，不是重新采集的真实噪声工况。原始数据、缓存和试运行中间文件在`work`；最终源码、配置、模型、正式预测和图表在`outputs`。

所有标准化、参考噪声功率、常数掩码、互信息、稳定性、冗余及选列仅fit当前训练折；验证折只用于选参；最终模型从头fit完整21人。测试评价前保存源码、配置与模型哈希，评价代码没有fit操作。全部噪声先加在连续记录再分窗，重叠样本共享同一噪声，所有方法共用相同测试噪声。

原定科学协议未变。补充的实现层配置只落实路径、数值下限、试运行规模、绘图和计时细节。运行时系统可用内存低于预设2 GiB提醒线，实际保留逐记录、逐条件、单线程处理并记录警告；没有因内存提醒减少噪声条件或随机种子。各阶段采样峰值RSS均低于1.5 GiB预算。

## 3. 正式主结果

下表为**受试者平均六类Macro-F1×100**，不是准确率。除干净条件外，每项先汇总3个训练种子×5个噪声种子，再对9名测试受试者等权平均。“高斯均值”对30/20/10/0/−5 dB五个预设条件等权，不代表实际噪声发生概率。

使用开发集选择的配置：B0为66维；其余方法均选择K=60。A1三个训练种子均选择λ=0.5，完整方案P均选择λ=0.25。B2/P的β固定0.1，全部C固定1。

### 与最接近实验基线B2的配对差异

差值单位为**Macro-F1百分点**。区间为先平均随机重复，再按9名受试者配对bootstrap 2000次所得95%百分位区间；它不反映大规模人群保证，也没有对所有探索性条件作多重比较校正。

| 比较条件 | P−B2 | 95%区间 | 可支持的表述 |
|---|---:|---|---|
| 开发集选择的K=60，干净 | −0.53 | [−0.76, −0.32] | 干净性能有小幅损失 |
| K=60，高斯20 dB | +0.75 | [+0.30, +1.22] | 本数据和该条件下有局部改善 |
| K=60，五级高斯均值 | −1.28 | [−1.57, −0.95] | 不支持总体高斯鲁棒性改善 |
| K=60，脉冲20 dB | −0.06 | [−0.33, +0.25] | 没有明确的改善证据 |
| 同预算K=20，五级高斯均值 | +0.89 | [+0.66, +1.09] | 较小特征预算下存在局部收益，不能据此换掉已确定部署配置 |
| 同预算K=40，五级高斯均值 | −0.51 | [−1.24, +0.25] | 方向为负，区间包含0 |

固定λ=0.5的诊断同样未呈现统一改善：P−B2五级高斯均值在K=20约+0.85个百分点、K=40约−0.99个百分点、K=60约+0.12个百分点，K=60区间包含0。详见paired_differences.csv中的fixed_lambda视角。所有对照均为原先预设，不是看到结果后添加的有利方案。

## 4. 实际发现与未解决问题

| 发现 | 事实与解释边界 |
|---|---|
| 初始整体改进假设未得到支持 | P在训练稳定性所用20 dB附近改善，但在10/0/−5 dB退化，五级均值较B2更低；应作为负结果报告 |
| 原定2个百分点工程目标未达到 | P在20 dB较B1只改善约0.76个百分点，未达到此前拟定的2个百分点；目标不是课程硬性评分条款 |
| 权重/特征预算的效果依赖条件 | 同K、固定λ和完整选择协议给出不同方向的差异；不能只挑K=20的有利结果作主结论 |
| 原验证目标有明确范围 | 验证目标权重为干净0.5、20 dB 0.25、10 dB 0.25，没有优化0/−5 dB或脉冲；这是设计中预设的适用边界，不能事后改权重提高测试分 |
| 机制原因仍待证实 | 单一20 dB稳定性估计可能不能覆盖强噪声，且稳定性不等于判别性；这是待检验解释，不是本次已证实的因果结论 |
| 静态活动仍有混淆 | P干净条件受试者平均召回：坐86.66%、站90.97%、躺100%；主流程没有解决所有类间混淆 |
| 不存在端到端加速证据 | 仍先计算完整66维，再选择60维；P实测端到端窗口摊销延迟未优于全部基线，不能凭维数减少声称更快 |
| 人群和设备外推有限 | 仅9名独立测试受试者、单设备/腰部佩戴、稳定活动过滤、人工噪声，不能声称真实部署可靠性 |
| 测试集现已使用 | 后续如改算法或训练目标，不能反复在同一9人上选“最好版本”；应另预设验证/测试设计或使用独立数据，并将本次结果作为既有证据保留 |

## 5. 实际耗时与内存

各程序阶段计时包含该命令的数据核验/读取等开销；不包括下载、环境安装、人工检查或聊天间隔。工作区已有数据和缓存；不能当冷启动性能承诺。

单线程开发集512窗批量、预热1次后每模型计时5次，3个训练重复的窗口摊销端到端中位数：B0 0.0897 ms、B1 0.0924 ms、B2 0.0862 ms、A1 0.0919 ms、P 0.0945 ms。它包含66维特征提取与分类，不含磁盘读写、等待2.56 s采样窗口和硬件采集延迟，也不是实时系统单窗响应保证；计时波动见原始inference_benchmark.csv。
